# pipelined_processor
An 8-bit 3-stage pipelined RISC processor in Verilog HDL with IF, ID, and EX stages. Supports ADD, ADDI, SUB, SLL, and HALT instructions. Features stall-based RAW hazard resolution, pipeline flushing on halt, and stable LED output. Verified through simulation, RTL elaboration, synthesis, and implementation in Vivado on Spartan-7 FPGA.
